# 固态电解质材料 AI 项目：100 篇文献试点

本仓库提供可下载到个人电脑运行的试点结果、代码与可视化。数据范围固定为第一阶段抽取的 100 篇文献。下载后无需启动服务器或 API，即可查看结构化数据、模型结果和交互式知识图谱。

## 快速开始：直接查看

1. 下载并解压 GitHub 仓库（或克隆仓库）。
2. 用 Chrome、Edge、Firefox 等现代浏览器打开 kg/knowledge_graph_interactive.html。
3. 即可拖动、缩放、搜索图谱；不需要 Python、依赖安装或网络连接。

也可以双击 kg/knowledge_graph_interactive.html。交互图是自包含的 HTML 文件，图数据已嵌入页面。

## 本地运行代码

Python 3.10 或更高版本。Windows、macOS、Linux 均可。

创建虚拟环境并安装轻量依赖：

    python -m venv .venv
    # Windows PowerShell: .venv\Scripts\Activate.ps1
    # macOS / Linux:
    source .venv/bin/activate
    python -m pip install -r requirements.txt

重新生成知识图谱 JSON/N-Triples、静态 SVG 及浏览器交互页：

    python scripts/build_kg.py
    python scripts/visualize_kg.py
    python scripts/visualize_kg_interactive.py

训练空气稳定性基线模型并更新评估结果：

    python scripts/train_model.py

查看 data/extracted_records.csv、data/extracted_records.json、kg/graph_stats.json、results/model_metrics.json 和 results/RESULTS.md。程序运行日志写入 logs/log.txt。

## 交互图谱说明

交互图谱展示第一阶段从文献结构化结果建立的实体关系网络。实体类型包括论文、电解质、元素、掺杂剂、合成方法、性能指标和稳定性；关系包括论文报告、组成元素、掺杂、合成方法、性能和稳定性关联。图谱文件同时提供 kg/graph.json 与 kg/graph.nt，方便后续图数据库导入；kg/knowledge_graph.svg 是静态预览。

页面操作：

- 搜索框：按材料或实体名称筛选。
- 类型菜单：只显示所选类型实体。
- 鼠标拖动节点：调整节点位置。
- 拖动空白处：平移画布。
- 滚轮：缩放。
- 点击节点：在右侧查看属性及相邻关系。
- “适应画布”：将当前可见节点重新置中。
- “重置布局”：恢复初始布局。

页面采用白色背景和黑灰节点连线，节点带柔和阴影；节点有轻微自然动态，鼠标经过时附近节点与连线轻缓跟随。选中节点名称突出显示，其相邻节点名称以较小字号显示。图谱是探索与展示工具，不代表关系已由人工逐条核验。

## 数据、限制与可复现范围

- 本阶段固定样本数：100 篇；清单见下方及 data/sample_manifest.csv。
- 结构化抽取值属于自动抽取候选结果，使用前应回到证据片段和论文核验。
- 稳定性分类标签数量有限，模型指标仅用于验证特征到训练评估的代码链路，不可解释为可靠的材料性能预测。
- 本仓库包含已生成的抽取数据、图谱、模型及结果，可在本地复现图谱与基线训练。
- 出于论文版权考虑，仓库不分发原始论文 Markdown。完整的“原文→LLM抽取”流程需要用户自行准备有权使用的 100 篇 Markdown 文件，并配置本地模型；仅查看结果、重建图谱和训练现有基线不需要原文或 LLM。
- 完整抽取脚本支持配置 SSE_SOURCE_DIR 与 SSE_LLM_MODEL；LLM推理还需安装适配环境的 PyTorch/Transformers。运行前请查看 scripts/sample_documents.py、scripts/extract.py 的参数说明。不会从仓库外自动扩大样本范围。
- 全部代码与输出均使用项目相对路径；没有服务器路径依赖，也没有 API 服务或后台服务。

    results/    指标、图表、结果摘要

    logs/       流程运行日志
    README.md   本地使用说明
